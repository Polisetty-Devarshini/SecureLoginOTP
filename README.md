# SecureLoginOTP 🔐

A secure login system with OTP verification developed using Python, Flask, and MySQL.

## 📌 About the Project

SecureLoginOTP is a web-based authentication system that provides secure user registration and login with OTP verification.

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML
- Bcrypt
- SMTP
- Git & GitHub

## ✨ Features

- User registration
- Secure password hashing
- User login
- OTP verification
- MySQL database integration
- Secure configuration using environment variables

## 🔒 Security

Sensitive information such as database passwords and secret keys are stored in a `.env` file and are excluded from GitHub using `.gitignore`.
